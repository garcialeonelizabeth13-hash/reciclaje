# Reciclaje

Aplicación Vue 3 para gestión de reciclaje.

## Configuración del Proyecto

```sh
npm install
```

### Compilar y recargar en caliente para desarrollo

```sh
npm run dev
```

### Compilar y minificar para producción

```sh
npm run build
```

### Previsualizar la compilación de producción

```sh
npm run preview
```

## Tecnologías

- Vue 3
- Vite
